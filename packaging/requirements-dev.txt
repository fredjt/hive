# Hive dev/test dependencies (not needed at runtime).
#
#   pip install -r packaging/requirements-dev.txt
#
# - pytest        the test runner (suite: python -m pytest tests/)
# - pytest-xdist  parallel execution (-n 8 is the sweet spot; the
#                 speedup is host-dependent — the subprocess-heavy
#                 lifecycle tests dominate on some boxes. See the root
#                 AGENTS.md, "xdist worker contract"). The suite is
#                 xdist-safe by construction: ephemeral ports, per-test
#                 temp dirs, in-process MCP servers. Beyond ~8-12
#                 workers, the subprocess-heavy lifecycle tests stop
#                 gaining speed.
# - pytest-cov    coverage (python -m pytest tests/ --cov=lib/hive_cli ...)
# - pytest-watch  watch loop: ptw --watch lib/ -- tests/  (re-runs on change)
# - ruff          CI's lint selection, runnable locally (the ruff-clean
#                 guard in tests/test_dashboard.py skips without it)
# pytest is capped below 9.2: 9.2.0 broke xdist's loadgroup
# distribution (upstream pytest-dev/pytest#15303 — xdist_group-marked
# tests scatter across workers, silently; the xdist fix,
# pytest-dev/pytest-xdist#1402, is unmerged/untagged). The suite's
# ordered e2e classes (the xdist worker contract) flake on exactly
# that. CI carries the same cap. Revisit when a fixed xdist ships.
ruff>=0.5
pytest>=8.0,<9.2
pytest-xdist>=3.6
pytest-cov>=5.0
pytest-watch>=4.0
